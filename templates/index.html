Questions and Answers

Everything you need to know about ClauseWise analysis and security.

Does ClauseWise store or train on my contracts?

No. ClauseWise operates strictly in RAM memory with zero database retention. Files are immediately purged from memory once the audit report is generated.

Is ClauseWise a replacement for an attorney?

No. ClauseWise is an informational pre-review tool. It empowers you by highlighting exposure points and preparing lawyer-ready questions, saving billable hours when you consult licensed counsel.

What file formats are supported?

ClauseWise supports PDF (.pdf), Microsoft Word (.docx), and plain text (.txt) documents up to 10MB.

How does side-by-side comparison work?

Our comparator aligns matching clauses between two draft versions, extracts differing terms, and computes which counterparty the revised language favors.
